# Photo reserve

Photographs that are kept but not published. Anything in `public/` is served to
the world at a guessable address even if no page links to it, so unused shots
live here instead.

- `kolhapur/`: unused frames from the Kolhapur shoot (3:2 landscape, 2000px).
- `stories/`, `home/`: earlier stand-in images, some filed under names that are
  not the women pictured. Do not publish these under those names.

To use one, move it back into `public/photos/…` and reference it from a page.
